# แผนผลิตภัณฑ์: ทำวีดีโอโดยไม่ต้องคิด prompt

เป้าหมาย: คนเลือก "แนว" ของช่องครั้งเดียว แล้วทุกตอนในโปรเจกต์ออกมาเป็นแนวนั้น
ส่วนที่เหลือเป็นปุ่มกดหรือช่องติ๊ก ไม่ต้องเขียน prompt ยาว ทุกอย่างที่ AI ทำลงบน
timeline เป็นชิ้นๆ ให้จิ้มแก้ได้ทีละจุด และเห็นผลทันทีโดยไม่ต้อง render

ตัวอย่างงานที่อยากได้: คลิปเล่าประวัติแบบกระดาษตัดแปะ (collage), เมือง 2.5D
แบบ isometric, ภาพแกะสลักวินเทจที่ขยับเป็นชั้นๆ คลิปพวกนี้ส่วนใหญ่ **ไม่ได้วาด
ทีละเฟรม** แต่เป็นภาพนิ่งหลายชั้น (พื้นหลัง, ตัวละคร, ป้ายข้อความ) ที่ขยับด้วย
keyframe: เลื่อน, ซูม, หมุน, เด้ง แอปนี้มี keyframe, ตัดพื้นหลัง (cutout) และ
title preset อยู่แล้ว สิ่งที่ขาดคือ "สูตร" และ "แหล่ง asset"

## สิ่งที่มีอยู่แล้วในแอป

| ต้องการ | สถานะ |
| --- | --- |
| โปรเจกต์ = โฟลเดอร์ | มีแล้ว (`concat.json` + ไฟล์ที่ clip ชี้ไป) |
| หลายวีดีโอในโปรเจกต์เดียว (EP) | มีแล้ว: timeline หลายแท็บ, export ทีละแท็บ |
| agent แก้ timeline สดๆ, Cmd-Z ได้ | มีแล้ว (live mode + sidebar) |
| Codex สร้างภาพลงโปรเจกต์ | มีแล้ว (`codex exec`, ทดสอบผ่าน) |
| ซับอัตโนมัติ | มีแล้ว (Whisper ในเครื่อง, timestamp ระดับคำ) |
| เสียงพากย์ | มี TTS ในเครื่อง (Kokoro); ElevenLabs ยังไม่มี |
| ตัดพื้นหลังภาพ/วีดีโอ | มีแล้ว (cutout model ในเครื่อง) |
| keyframe, effect, transition | มีแล้ว (127 package) |
| template ที่มีช่องให้เติม | มีโครงแล้ว (`template_instantiate` + slot) |
| ตัด dead air | ยังไม่มี แต่ทำได้จาก timestamp ของ Whisper |

## โครงโฟลเดอร์ของโปรเจกต์ (ช่อง)

```
ช่องประวัติศาสตร์/
  concat.json        timeline ทุกตอน (EP01, EP02, ... เป็นแท็บ)
  CLAUDE.md          แนวของช่อง: น้ำเสียง, จังหวะ, สไตล์ภาพ, กฎของช่อง
  .claude/skills/    สูตรของแนวนี้ (hook, บท, การจัดชั้นภาพ, ...)
  style.toml         ค่าที่ปุ่มต่างๆ ใช้: ขนาดเฟรม, ฟอนต์, สี, เสียงพากย์, เพลง
  characters/        identity pack ต่อคน (แบบ my-avatar-identity)
  assets/            ของที่คนใส่เอง: โลโก้, รูปจริง, เพลง
  generated/         ของที่ Codex สร้าง, แยกเป็นชั้น, พื้นหลังใส
  sources/           รูปจากเว็บพร้อมเครดิต, ภาพหน้าเว็บที่ capture มา
  scenes/            clip ที่เขียนด้วยโค้ด (three.js / HTML)
  renders/           ไฟล์ที่ export แล้ว
```

เพราะ sidebar รัน `claude` โดยมีโฟลเดอร์โปรเจกต์เป็น cwd อยู่แล้ว `CLAUDE.md` กับ
`.claude/skills/` ในโฟลเดอร์จะถูกโหลดให้ agent อัตโนมัติ: "แนวของช่อง" จึงเป็นแค่
ไฟล์ในโฟลเดอร์ แก้ได้ แชร์ได้ ทำ template ขายได้ (ต้องเปิด tool `Skill` เพิ่มจาก
ที่เปิดแค่ `Bash` ตอนนี้)

แอปคอยดูโฟลเดอร์: ไฟล์ใหม่ใน `assets/`, `generated/`, `sources/` ขึ้นใน media bin
เอง ไม่ต้องกด Import

## Phase A: ภาพเป็นชั้น + stop motion + ตัวละครหน้าเดิม

สิ่งที่ทำต่อจากขั้น Codex ที่เพิ่งเสร็จ

1. **asset พื้นหลังใส**: สั่ง Codex ให้ได้ PNG โปร่งใส ถ้าได้ภาพมีพื้นหลัง ใช้
   cutout ในเครื่องตัดให้ (มีอยู่แล้ว) เก็บเป็น `generated/<ชื่อ>.png`
2. **ภาพเป็นชั้น**: หนึ่งฉากสร้าง 3 ถึง 4 ไฟล์: พื้นหลัง, ชั้นกลาง, ตัวหลัก,
   ของประกอบ วางเป็น clip ซ้อนกันคนละ lane แล้วใส่ keyframe ให้ขยับต่างความเร็ว
   (parallax) ได้ 2.5D แบบในตัวอย่าง
3. **ตัวละครหน้าเดิม (identity lock)**: `characters/<ชื่อ>/` เก็บภาพอ้างอิงและ
   สัญญาหน้าตา (แบบ my-avatar-identity) แอปส่งภาพอ้างอิงให้ Codex ด้วย
   `codex exec -i <ภาพ>` ทุกครั้งที่ภาพมีตัวละครนั้น
4. **stop motion**:
   - agent เขียน shot list (เช่น 8 ถึง 12 ท่าหลัก) แล้วให้ Codex สร้างเฟรมแรก
   - เฟรมต่อไปส่งเฟรมก่อนหน้า + identity pack เป็น `-i` เพื่อให้ต่อเนื่อง
   - เก็บที่ `generated/stopmotion/<ชื่อ>/0001.png ...`
   - วางด้วยคำสั่ง `AddClipsInSequence` (มีแล้ว) เฟรมละ 2 ถึง 3 เฟรมวิดีโอ
   - คนลากสลับ ลบ หรือสั่ง "ทำเฟรม 5 ใหม่" ทีละเฟรมได้
   - ข้อจำกัด: Codex ใช้ประมาณ 1 นาทีต่อภาพ 24 เฟรมคือราว 24 นาทีถ้าทำทีละภาพ
     แนะนำ "ท่าหลักน้อยเฟรม + ขยับกล้อง + ชั้นภาพ" มากกว่าวาดทุกเฟรม และให้แอป
     รัน Codex หลายตัวพร้อมกันได้

## Phase B: template แนววีดีโอ (สำคัญที่สุด)

template หนึ่งตัวคือโฟลเดอร์ที่มีครบทั้งสูตร:

- ตัวอย่างวีดีโอสั้นๆ ให้ดูตอนเลือก
- `CLAUDE.md` + skills: วิธีคิด hook, โครงบท (hook 3 วิ, ปูเรื่อง, จังหวะ, ปิด)
- สไตล์ภาพสำหรับ Codex (เช่น "Victorian engraving, cut-out collage")
- title preset, สไตล์ซับ, transition, ฟอนต์, สี, เพลง, เสียงพากย์
- โครง timeline เริ่มต้น (lane สำหรับพื้นหลัง, ตัวละคร, ป้าย, ซับ, เสียง)

หน้า New Project เปลี่ยนเป็น "เลือกแนว" มีการ์ดพร้อมตัวอย่าง เลือกแล้วได้โฟลเดอร์
ช่องที่ตั้งค่าครบ การเพิ่มตอนใหม่ = เพิ่มแท็บ timeline ที่ใช้แนวเดิม

แนวแรกที่ควรทำ (จากตัวอย่าง): เล่าประวัติแบบกระดาษ collage, เมือง/แผนที่ 2.5D,
ภาพแกะสลักวินเทจ

## Phase C: ปุ่มกด/ติ๊ก แทน prompt

แผง "Actions" ข้าง sidebar แต่ละปุ่มคือ prompt สำเร็จรูปที่ส่งให้ agent หรือคำสั่ง
ตรงของแอป:

- ตัด dead air (ช่วงเงียบจาก timestamp ของ Whisper, ปรับความยาวขั้นต่ำได้)
- ใส่ซับทั้งตอน (มีแล้ว) ในสไตล์ของช่อง
- คิด hook 5 แบบ, เขียนบทจากหัวข้อ, แตกบทเป็นฉาก
- พากย์เสียงทั้งบท (ElevenLabs หรือเสียงในเครื่อง)
- เติมภาพประกอบทุกช่วงที่ว่าง (Codex ตามสไตล์ช่อง)
- ทำเป็น 9:16 / 1:1 / 16:9

ช่องติ๊กระดับช่อง (ใน `style.toml`): ตัด dead air ทุกครั้ง, ซับอัตโนมัติ,
ใส่โลโก้มุมจอ, เพลงพื้นหลัง

## Phase D: แหล่ง asset

- **ElevenLabs**: ใส่ API key ใน Settings (เก็บใน Keychain) พากย์ทั้งบท ได้
  timestamp ระดับคำมาด้วยทำให้ซับตรงเสียงทันที
- **รูปบุคคลจริง / เหตุการณ์จริง** (สร้างไม่ได้และไม่ควรสร้าง): ค้นจาก
  Wikimedia Commons ก่อน (ฟรี, มี license ชัด) เก็บใน `sources/` พร้อมไฟล์เครดิต
  แหล่งอื่นต้องบอกคนว่าลิขสิทธิ์ไม่ชัด
- **icon / logo**: Iconify (icon เปิด), Simple Icons (โลโก้แบรนด์) โลโก้ของคนอื่น
  ใช้ได้เท่าที่กฎหมายเครื่องหมายการค้าอนุญาต
- **หน้าเว็บจริง**: capture เต็มหน้าด้วย headless browser แล้ววางเป็นภาพยาว
  ใส่ keyframe เลื่อน/ซูม หรือแยกเป็นส่วนๆ ให้ animate

## Phase E: clip ที่เขียนจากโค้ด

clip ชนิดใหม่ชี้ไปที่ `scenes/<ชื่อ>.html` (three.js, canvas, SVG) แอปเรนเดอร์
เป็นเฟรมด้วย headless browser เก็บ cache แล้วแสดงเหมือนวีดีโอ แก้โค้ดแล้ว
เรนเดอร์ใหม่เองเบื้องหลัง scene ต้องมี `renderFrame(t)` ให้แอปคุมเวลาได้ ต้อง
ออกแบบละเอียดก่อนลงมือ (headless browser ตัวไหน, ความเร็ว, เสียง)

## Phase F: ง่ายสำหรับคนทั่วไป

- โหมดง่าย: แสดงแค่ sidebar, การ์ดแนว, ปุ่ม Actions, preview และ timeline
- โหมดเต็ม: editor ทั้งหมดแบบตอนนี้
- ซ่อนหรือลบ panel ที่ไม่ใช้ได้ (dock รองรับอยู่แล้ว) และจำไว้ต่อโปรเจกต์

## ลำดับที่แนะนำ

1. Phase A ข้อ 1 ถึง 3 (ชั้นภาพ, พื้นหลังใส, identity) เพราะต่อจากของที่เพิ่ง
   เสร็จและเป็นฐานของ template ทุกแนว
2. Phase B template แนวแรก 1 ตัวให้ครบวงจร (เลือกแนว, ได้ช่อง, สั่งทำตอน)
3. Phase C ปุ่ม dead air, hook/บท, พากย์
4. Phase D ElevenLabs และรูปจริงจาก Wikimedia
5. Phase A ข้อ 4 stop motion, Phase E code clip, Phase F โหมดง่าย
